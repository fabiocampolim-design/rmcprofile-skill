# rmcprofile-skill

An AI-agent skill, verified Python toolkit, executed chapter notebooks and an
undergraduate course on Reverse Monte Carlo modelling of total scattering data
with [RMCProfile](https://rmcprofile.ornl.gov/).

RMCProfile itself is not included: download it from the RMCProfile site, install
it, and set `RMCPROFILE_HOME` to its `RMCProfile_package` directory. Everything
in this repository that does not need the binary works without it.
