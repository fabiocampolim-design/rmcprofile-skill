L0 · Welcome — why local structure notebook §0–1

What a crystal's average structure leaves out, what total scattering measures instead, and how this course and its notebooks run.

Key ideas

  • A crystal structure is an average: one position per site, one displacement ellipsoid. Real materials disorder, tilt, hop and vibrate — and their properties live in that difference.
  • Each lecture is one run of slides: a picture first, the physics next, the equations last. Notebook sections are given for every lecture.
  • The deck is flat and linear: → is the only key you need. Every lecture opens with a divider and runs from its simplest slide to its most mathematical.

Equations

  • gij(r) = nij(r) / ( 4π r2 ρ cj Δr ) — partial pair distribution
  • G(r) = Σij ci cj bi bj [ gij(r) − 1 ] — Keen's G(r), in barn
  • G(r → 0) = − ( Σi ci bi )2 — its exact limit

L1 · Scattering and the PDF notebook §1–4

Partial pair distribution functions, thermal broadening, Keen's G(r), D(r) and T(r) with their exact limits, and the Fourier route to F(Q).

Key ideas

  • Take a box of atoms, measure every pair distance, sort them into bins: the partial pair distribution functions. On an ideal NaCl lattice they are spikes at the shell distances.
  • Displace every atom by a Gaussian of 0.05 Å and the spikes become peaks whose width is the pair's relative displacement — this is what a real material's PDF looks like.
  • The partials are weighted by concentrations and scattering lengths into one measurable function. Three conventions differ by factors of r; each has an exact limit the notebook checks.
  • The same box in reciprocal space: Faber–Ziman partials Sij(Q) − 1 by a sine transform of gij − 1, and their weighted sum F(Q). A finite box rings.

Equations

  • Sij(Q) − 1 = 4π ρ ∫0rmax r2 [ gij(r) − 1 ] sin(Qr)/(Qr) dr — Faber–Ziman partial
  • F(Q) = Σij ci cj bi bj [ Sij(Q) − 1 ] — total scattering
  • D(r) = 4π r ρ G(r),   T(r) = D(r) + 4π r ρ ( Σ c b )2 — the other conventions

L2 · Monte Carlo and Metropolis notebook §5–6

One atom moves, a histogram updates, a chi-squared changes; the Metropolis rule decides — the whole algorithm in one move.

Key ideas

  • Pick one atom. Displace it by a random amount up to a maximum. Recount only the pairs that atom belongs to. Compare the new histogram with the target. Keep or undo.
  • The distance between the calculated and the target function is a sum of squared residuals over bins, each divided by an uncertainty σ. A move that lowers χ² is always kept; one that raises it is kept sometimes.
  • The notebooks' own reverse Monte Carlo engine reuses the toolkit's grid and normalisation, so what it fits is exactly what RMCProfile tabulates.

Equations

  • χ2 = Σdata Σk [ fcalc(rk) − fdata(rk) ]2 / σ2 — chi-squared
  • Δ = Δχ2/2 + ΔU/kBT,   accept if Δ ≤ 0, else with probability e−Δ — the decision
  • U = ½ k ( d − d0 )2 — harmonic bond term

L3 · Reverse Monte Carlo notebook §7–9

From the average structure to the data: what a fit reproduces (the pair distribution), what it does not (the coordinates), and why constraints are physics.

Key ideas

  • Start rmclite on the ideal NaCl lattice with the thermal box's partials as targets: the spikes broaden into the target peaks and χ² falls by four orders of magnitude.
  • The fit reproduces the pair distribution; it does not recover the coordinates. The residual against the target is as small as that of a second, independent thermal realisation — and the atoms are not where the truth put them.
  • A pair distribution constrains distances, not chemistry. A closest approach, a distance window, a coordination number or a bond potential is physics the data cannot say and the fit needs.

Equations

  • gij(r) ∝ Σpairs δ( r − | ra − rb | ) — what the target fixes
  • { ua } → { uπ(a) }  for any π that preserves the shell statistics — a symmetry of the fit
  • rms( gfit − gtarget ) ≈ rms( grealisation 2 − gtarget ) — the honest residual

L4 · Preparing a run notebook §10–14

A unit cell becomes a supercell and an rmc6f file; the .dat keyword file and the checker; synthetic data with a known answer.

Key ideas

  • RMCProfile needs a box: a cell, a list of sites with fractional coordinates, and how many times to repeat it. The toolkit's build_configuration turns a crystallographic description into an rmc6f file.
  • Fold every atom of the supercell into one unit cell and the displacement clouds of the sites appear; average the folded positions and the unit cell is back. Export to XYZ or CIF for any viewer.
  • One text file drives a run: scalars, data blocks with subordinate keywords, and bare flags. The toolkit writes a complete synthetic set in one call and keeps the three keyword forms apart.
  • RMCProfile stops on a missing file with exit code 0 and waits forever for a missing .poly file. The toolkit's checker reports the mistakes the manual warns about — and the ones it does not — before the binary starts.

Equations

  • xa = xaideal + ua,   ua ~ N(0, 0.05 Å) per Cartesian component, seed 0 — truth box
  • Gdata(rk) = Gtruth(rk) + N(0, 0.003 barn) — data
  • rk = k·Δr,   Δr = 0.02 Å,   rmax = 8 Å < L/2 = 8.46 Å — grid

L5 · Fitting with RMCProfile notebook §15–18

RMCProfile computes what the toolkit computes; a real refinement of synthetic neutron data; CONVOLVE and the finite box; the same data through rmclite.

Key ideas

  • Run the program with TIME_LIMIT 0 on the ideal lattice against the synthetic data: no moves, one evaluation. Its calculated G(r) is the toolkit's, and its experiment column is our data.
  • Half a minute of moves on the CUDA build: tens of thousands of moves, χ² from ten thousand to order ten, and the calculated G(r) on the data within the noise.
  • A reciprocal-space fit against F(Q) must account for the box: RMCProfile convolves its calculated F(Q) with the box function. The keyword's empty value is not optional.
  • Feed the same synthetic G(r) to the notebooks' engine: it converges to the same pair distribution, slower and in the open — every step readable.

Equations

  • Fbox(Q) = ∫ F(Q′) M(Q − Q′) dQ′,   M(Q) = (1/π) ∫0rmax cos(Qr) dr = sin(Q rmax) / (π Q) — truncated transform
  • Fcalc → Fcalc ⊗ M,   Fdata → Fdata ⊗ M — what CONVOLVE does
  • χ2F = ΣQ [ (Fcalc ⊗ M)(Q) − (Fdata ⊗ M)(Q) ]2 / σ2 — the fitted quantity

L6 · Constraints as physics notebook §23–27

Closest approach, distance windows, bond potentials, fixed coordination and bond valence sums — measured on refined boxes.

Key ideas

  • A fit that reproduces G(r) can still put two chlorines where a sodium belongs, break a coordination polyhedron, or let an atom drift through a wall of neighbours. Constraints say what the data cannot.
  • One number per pair below which no two atoms may come. Raise the Na–Cl minimum above the inner edge of the thermal shell and the refined box cannot reach the data's peak from below.
  • Three ways to keep the neighbours you start with. Chapter 6 runs each for six seconds and measures the box RMCProfile saved.
  • A bond valence sum turns a coordination shell into a chemical check: it should equal the ion's oxidation state. RMCProfile's BVS :: block restrains the fit toward the nominal valences; the toolkit computes the same quantity on any box.

Equations

  • Paccept = 0  if  dab < dminij  or  dab ∉ [ MNDIST, MXDIST ] — hard wall
  • ΔU/kBT,   U = ½ k ( d − d0 )2  for | d − d0 | ≤ STRETCH_SEARCH — bond potential
  • Va = Σb exp[ ( R0 − dab ) / b ],   χ2BVS = w Σa ( Va − Vnominal )2 — bond valence sum

L7 · Corrections notebook §28–31

What the instrument does to G(r) and what RMCProfile does about it — measured, not assumed: the damping is Gaussian, the nanoparticle keyword corrects the baseline.

Key ideas

  • A measured F(Q) ends at a finite Qmax and is smeared by the instrument's resolution; its transform is damped at large r and its peaks are broadened. RMCProfile corrects the calculated function to look like the data.
  • The manual describes RESOLUTION_CORRECTION as exp(−r·Expo). The ratio of RMCProfile's calculated columns with and without the keyword is exp(−(α r)²/2) to 10⁻³ — PDFgui's Qdamp form — and departs from the exponential by 0.25 at 8 Å.
  • Synthesise data from the truth box's G(r) damped by exp(−(0.05 r)²/2). Evaluate the truth box against them with no correction, with α = 0.05 and with α = 0.20: the right α has the lowest χ².
  • Finite Q-resolution broadens each peak in r by an amount growing with r: a Gaussian of σ = β r (manual Appendix F). Synthetic data broadened that way are fitted best by the same β.
  • Measured the same way, PARTICLE_RADIUS does not scale the peaks by a shape function. Beyond the closest approach it adds −G₀·[1 − f(r)] with f the spherical shape function of diameter 2R: the bulk baseline replaced by the envelope-weighted one, to 0.01 barn rms.

Equations

  • Gcalc(r) → Gcalc(r) · exp[ −(α r)2 / 2 ] — damping (RESOLUTION_CORRECTION α)
  • Gcalc(r) → ∫ Gcalc(r′) N( r − r′ ; σ = β r ) dr′ — broadening (BROADENING_CORRECTION β)
  • Gcalc(r) → Gcalc(r) − G0 [ 1 − f(r) ],   f = 1 − 3r/2D + r3/2D3,   D = 2R — nano-size (PARTICLE_RADIUS R, BULK_RHO ρ)

L8 · Beyond neutrons notebook §19–22, §32–34

X-ray form factors and contrast, an honest X-ray run, Bragg profiles from a Rietveld refinement, EXAFS on the shipped exercise, magnetic and diffuse fits described.

Key ideas

  • A neutron's scattering length is a constant per isotope; an X-ray's is the atomic form factor f(Q): Z electrons at Q = 0, falling with Q. The ratio between two elements is not constant, so an X-ray F(Q) mixes the partials with Q-dependent weights.
  • Neutrons weigh Cl–Cl most (3.63 versus 9.58 fm); X-rays weigh Na–Cl more and the balance drifts with Q. Two data sets on one box see different partials — the reason to fit both.
  • The X-ray block runs, reports χ², returns our data exactly in its experiment column, and its calculated column has our scale — median ratio 0.999 — but its shape agrees with ours only to a correlation of 0.90, and neither NORMALIZATION_TYPE value changes it.
  • RMCProfile is the RMC code that fits the Bragg profile together with the PDF. The BRAGG block needs four files from a Rietveld program; on the shipped SF₆ exercise the toolkit reads them, the program evaluates the profile, and the shipped configuration reproduces it with correlation 0.998.
  • The EXAFS block fits the absorption fine structure χ(k) of one absorbing element, computed from the box with FEFF-style path amplitudes. The shipped SnO exercise evaluates two edges in eleven seconds at TIME_LIMIT 0 and writes k-space and r-space outputs per edge.
  • Two data types this course cannot reproduce with its own engine and the package ships no exercise for: the notebooks document their keyword blocks so a reader with such data knows what the program expects.

Equations

  • FX(Q) = Σij ci cj fi(Q) fj(Q) [ Sij(Q) − 1 ] / ( Σi ci fi(Q) )2 — toolkit's X-ray F(Q)
  • … / Σi ci fi(Q)2   (NORMALIZATION_TYPE :: <f^2>, the default) — the other convention
  • f(s) = Σk=1..4 ak exp( −bk s2 ) + c,   s = Q / 4π — Cromer–Mann form

L9 · Reading a configuration notebook §35–38

A refined box is a statistical object: coordination numbers, bond lengths, bond angles, displacement clouds and ensembles.

Key ideas

  • What one reads off a box must be distributions — coordination numbers, bond lengths, bond angles, displacement clouds — never the position of a particular atom. Four analyses, each checked against the answer the synthetic truth knows.
  • In rock salt every Na keeps six Cl within 3.2 Å whatever the thermal motion: the histogram is a single bar, 6 : 108. The Na–Cl bond from the fitted box is 2.822 ± 0.074 Å against the truth's 2.822 ± 0.072 Å.
  • Cl–Na–Cl angles peak at 90° and 180°, broadened by the thermal displacements; the fit's 90° peak sits at 89.9° with a spread of 2.08° against the truth's 2.02°. The right panel is every Na's displacement from its own ideal site — the cloud a displacement ellipsoid summarises.
  • One fitted box carries the statistical noise of its 216 atoms. Four fits from different seeds, averaged, are closer to the target than any single fit — and the spread between them is the honest error bar of anything read off a box.

Equations

  • ⟨d⟩ = Σshell rk3 g(rk) / Σshell rk2 g(rk),   σd2 = Σ rk2 g(rk) ( rk − ⟨d⟩ )2 / Σ rk2 g(rk) — bond length from the partial
  • ua = [ xa − xaideal − round( xa − xaideal ) ] · L — displacement from the ideal site
  • ḡ = (1/N) Σn gn,   rms( ḡ − gtarget ) < minn rms( gn − gtarget ) — ensemble estimate

L10 · Contributing to RMCProfile notebook §39–40

The live cross-check and what it costs, the ecosystem around RMCProfile, and how findings become reports the developers can use.

Key ideas

  • Everything the notebooks compute on their own is compared with the package's output on the package's own exercise: partials equal to 2.8×10⁻⁴ (its single precision), G(r) to 3×10⁻⁵ barn, on both builds, against recorded tolerances that were measured, not chosen.
  • RMCProfile's site lists the neighbours it considers relevant; one honest line each, no ranking.
  • RMCProfile is closed-source, so contributions are reports, reproductions and documentation — through its mailing list, under the contributor's own name. The study behind this course keeps a ledger; every entry has a run log, a file and a line.

Equations

  • R(r) = Gcalcwith(r) / Gcalcwithout(r)  away from zero crossings — multiplicative keyword
  • Δ(r) = Gcalcwith(r) − Gcalcwithout(r) — additive keyword
  • max | R − exp(−(αr)2/2) | < 10−3,   rms | Δ + G0(1 − f) | < 0.02 barn — the verdict

Glossary

pair distribution function (PDF)
the distribution of interatomic distances in a sample; g_ij(r) per pair of types, G(r) the weighted total
partial g_ij(r)
pairs of types i and j at distance r, normalised so that a structureless gas gives 1
Keen's G(r)
Σ c_i c_j b_i b_j [g_ij(r) − 1] in barn; tends to −(Σcb)² at r → 0
D(r), T(r)
4πrρ G(r), and D(r) plus 4πrρ(Σcb)²; the other two real-space conventions RMCProfile accepts
F(Q)
the total scattering function in reciprocal space; the Fourier pair of G(r)
Faber–Ziman partial S_ij(Q)
the sine transform of g_ij(r) − 1; the reciprocal-space partial
scattering length b
a nucleus's neutron scattering amplitude, constant in Q; in femtometres
form factor f(Q)
an atom's X-ray scattering amplitude, Z electrons at Q = 0, falling with Q
reverse Monte Carlo (RMC)
moving atoms of a large box at random and keeping the moves that bring its calculated functions closer to the data
Metropolis rule
accept a move that lowers χ² always, one that raises it with probability exp(−Δχ²/2)
χ² (chi-squared)
the sum over bins of squared residuals between calculated and target functions divided by σ²
σ (sigma)
the uncertainty per bin that scales how strongly a data set pulls; effectively the data's temperature
supercell
the unit cell repeated n × m × l times to make the RMC box
rmc6f
RMCProfile's configuration file: cell, atom types, and each atom's fractional position with site and cell indices
.dat file
the keyword file that drives a run: scalars, data blocks with subordinate keywords, flags
TIME_LIMIT 0
a run that evaluates the starting box against the data and makes no move; deterministic
MINIMUM_DISTANCES
the closest approach per pair of atom types, in the order AA AB AC BB BC CC
DISTANCE_WINDOW
per-pair lower and upper bounds that also freeze the neighbour list at the start
bond valence sum
Σ exp[(R₀ − d)/b] over an atom's neighbours; should equal the oxidation state
CONVOLVE
the keyword that convolves the calculated F(Q) with the box function so a truncated transform is fitted consistently
RESOLUTION_CORRECTION
damping of the calculated real-space function by exp(−(αr)²/2), as measured on 6.7.9
BROADENING_CORRECTION
convolution of the calculated function with a Gaussian of width βr
PARTICLE_RADIUS / BULK_RHO
the nanoparticle correction: the bulk baseline replaced by the shape-function-weighted one beyond the closest approach
shape function f(r)
the fraction of pair vectors of length r that fit inside a sphere of diameter D: 1 − 3r/2D + r³/2D³
Bragg profile
the powder diffraction pattern of the average structure; RMCProfile fits it together with the PDF
EXAFS χ(k)
the X-ray absorption fine structure of one absorbing element, a sum over scattering paths from its neighbours
displacement cloud
the distribution of an atom's displacements from its ideal site over a box; what a displacement ellipsoid summarises
ensemble
several independent RMC fits of the same data; their mean is the estimate and their spread the error bar
cross-check
comparing the toolkit's functions with RMCProfile's own output columns on the same box, to a recorded, measured tolerance
rmclite
the notebooks' clean-room reverse Monte Carlo engine, small enough to read
